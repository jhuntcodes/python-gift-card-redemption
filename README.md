PROJECT TITLE: Gift Card Redemption Simulator
    Very Beginner python project that simulates redeeming purchases from a gift card balance
    WHAT DOES IT DO?
    - Checks if user has enough money to make purchase
    - Will deny purchase if over the balance
    - Will update balance after successful purchases
    BUILT USING: Python
    WHAT AM I LEARNING THROUGH THIS PROJECT?
    - Variables
    - User input
    - If/else statements
    - Basic Programming knowledge
